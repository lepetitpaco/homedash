Installer homedash

Cinq minutes, une seule fois. Les mises à jour se font ensuite toutes seules.

  1. Télécharge l'appli

    Prends le fichier .dmg qui correspond à ton Mac :

    Apple Silicon (M1, M2, M3, M4…) : homedash-…-arm64.dmg
    Intel (Mac plus anciens) : homedash-…-x64.dmg

    Télécharger pour Mac
    Tu ne sais pas lequel ? → À propos de ce Mac : « Puce Apple M… » = Apple Silicon, « Processeur Intel » = Intel.

  2. Installe-la

    Ouvre le .dmg et glisse l'icône homedash dans le dossier Applications.

  3. Ouvre-la une première fois

    Lance homedash depuis Applications. macOS affiche « Apple n'a pas pu confirmer que homedash ne contenait pas de logiciel malveillant ». C'est normal : l'appli n'est pas (encore) signée par Apple.

    Clique Terminé. Surtout pas Placer dans la corbeille.

  4. Autorise-la

    Ouvre Réglages Système → Confidentialité et sécurité, descends tout en bas : à côté de « homedash a été bloqué », clique Ouvrir quand même, puis ton mot de passe, puis Ouvrir.

    Le bouton n'y est pas ? Relance homedash une fois, puis reviens dans ces réglages. Ou, dans le Terminal : xattr -dr com.apple.quarantine /Applications/homedash.app

  5. C'est parti

    homedash s'ouvre. La carte 👋 Pour commencer te guide : ajoute tes sites, tes liens, et branche ce dont tu te sers.

    Le trousseau demande l'accès à « homedash Safe Storage » ? Toujours autoriser : c'est là que homedash range tes connexions.

  1. Télécharge l'installateur

    Le fichier homedash-…-setup.exe.

    Télécharger pour Windows

  2. Lance-le

    Double-clic sur le fichier téléchargé. Windows affiche « Windows a protégé votre ordinateur » : c'est normal, l'appli n'est pas (encore) signée par Microsoft.

  3. Autorise-le

    Clique Informations complémentaires, puis Exécuter quand même. homedash s'installe et s'ouvre.

    Ton navigateur bloque le téléchargement ? Dans la liste des téléchargements : … → Conserver.

  4. C'est parti

    La carte 👋 Pour commencer te guide : ajoute tes sites, tes liens, et branche ce dont tu te sers. homedash se retrouve dans le menu Démarrer.

Mettre à jour

Rien à faire : quand une nouvelle version sort, homedash te la propose. Un clic sur Mettre à jour, l'appli sauvegarde tes données, se remplace et se relance. Pas de nouvelle autorisation à donner.

Fermer, quitter

Fermer la fenêtre garde homedash ouvert en arrière-plan, pour tes notifications. Pour l'arrêter vraiment : ⌘Q sur Mac, ou clic droit sur son icône près de l'horloge → Quitter sous Windows.

Désinstaller

Mac : glisse homedash d'Applications à la corbeille. Pour effacer aussi tes données : le dossier ~/Library/Application Support/homedash.
Windows : Paramètres → Applications → homedash → Désinstaller. Tes données sont dans %APPDATA%\homedash.

Un souci ?

Dans homedash : Réglages → Aide. Sinon, dis-le nous.
