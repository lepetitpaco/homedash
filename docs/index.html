Installer

Mac

  1. Ouvre le .dmg et glisse homedash dans Applications.
  2. Au premier lancement, macOS prévient : clique Terminé.
  3. Réglages Système → Confidentialité et sécurité, tout en bas : Ouvrir quand même.

Une seule fois : l'appli n'est pas signée par Apple. Les mises à jour passent ensuite toutes seules.

Windows

  1. Lance le setup.exe.
  2. « Windows a protégé votre ordinateur » : Informations complémentaires.
  3. Exécuter quand même.

Ensuite, la carte Pour commencer de l'accueil te guide pas à pas.
